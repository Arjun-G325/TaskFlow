# TaskFlow demo walkthrough

Use two browser profiles or one private window so the owner and teammate are signed in as different accounts.

1. Register or sign in as the project owner. Create a project and add the teammate by their TaskFlow email address.
2. Sign in as the teammate and open the project. The project-added notification should appear.
3. As the owner, create a task, optionally use AI Assist, review the description and subtasks, assign the teammate, and save.
4. As either member, open the task details. Complete a subtask, add a comment, and review its history.
5. Move the task across the To do, In progress, and Done columns. A status notification should reach the other task participant.
6. Open Activity to filter the event feed by project member.
7. Open Progress to view task status, completion, overdue count, member workload, and weekly completions.
8. Use the notification menu to open a related task/subtask and mark notifications read.

AI Assist requires `GEMINI_API_KEY`. Email signup requires valid Brevo settings. Google sign-in requires the same OAuth client ID in the backend and frontend environment files, with the browser origin authorized in Google Cloud.
